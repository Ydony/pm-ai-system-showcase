# PM AI System

**An AI delivery team that plans, builds and reviews software tasks on its own, while a human only approves direction and merges.**

For a solo builder who wants several projects moving at once without becoming a full-time project manager.

**Status:** in daily use on all of my projects.

## Results so far

- Work is planned as epics, features and tasks, with a size, a risk level and a reviewer for every task.
- Ready tasks are picked up and built automatically, each in its own isolated workspace, and come back as a pull request.
- Every change is reviewed and tested before the owner decides to merge.
- Cost and progress of every task are tracked, and a control panel shows what is running.
- Projects keep their code private while the work continues.
